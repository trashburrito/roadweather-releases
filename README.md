# RoadWeather — downloads

A free, ad-free weather app for Android, made for over-the-road truck drivers: current conditions, hourly and daily
forecast, radar, wind and snow maps, and road conditions along the way. English and Spanish.

This repository only holds the installable app. **Download the latest version from
[Releases](https://github.com/trashburrito/roadweather-releases/releases/latest)** (the `RoadWeather-<version>.apk` file).

## Install (Android 8 or newer)

1. On the phone, open the latest release link above and tap **RoadWeather-1.2.apk** to download it.
2. Open the downloaded file. If Android asks, allow **Install unknown apps** for the browser or Files app you used.
3. Tap **Install**. Google Play Protect may say the developer is unknown: tap **More details → Install anyway**.
4. Open RoadWeather and allow location so it shows the weather where you are.

**Updating:** install the newer APK the same way; it replaces the old one and keeps your saved places.
**Coming from version 1.1:** uninstall 1.1 first (write down your saved places, then add them again), because 1.1 was a
test build. From 1.2 on, updates install over the top.

## Weather data

Free public sources, each labelled in the app with its time and whether it is observed or a forecast:
U.S. National Weather Service, NOAA nowCOAST and NOHRSC, RainViewer, Open-Meteo, OpenFreeMap / OpenStreetMap, Photon.
When data is missing, old or the phone is offline, the app says so instead of guessing.
